Historical implementation record. The current rules use only seven weekday pattern-count maps; see [the 2026-10-27 contract](pattern-count-only-2026-10-27.md). The operating-hours and work/rest descriptions below record the earlier Lab design.

The isolated Lab Rules page now selects one weekday at a time. Its single daily form contains preparation/opening/closing clocks, opening headcount, opening qualification, segment headcount and complete-pattern minimums. The former base-day form, seven-row pattern table, date-specific editor, weekday-copy buttons and numeric work/rest-limit editor are absent from the regular page. Complete-pattern definitions and their break structure remain in a separate shared editor.

Saving a rule materializes all seven weekdays, clears legacy date and employee-limit overrides, and sets `enforce_work_rest_limits=false`. Historical rule versions and runs remain unchanged. Legacy versions retain their old limits when replayed. Availability, qualification, non-overlap and configured pattern breaks remain mandatory. A new rule with numeric work/rest limits disabled is exploratory and cannot pass the reviewed real-run gate. The Lab has no formal shift-write endpoint.
