# Weekday pattern counts, 2026-10-27

The current Lab Rules form defines complete shift patterns once and sets their minimum counts independently for Monday through Sunday. The rule JSON and newly saved SQLite versions contain `base_day.patterns` and seven `weekly[weekday].pattern_minimums` maps. They do not contain operating hours, opening staff counts, interval demand, date overrides or numeric work/rest limits. Pattern breaks retain only count, duration and paid status; no break occurrence time is required.

`STRICT` requires every daily pattern count. `BEST_EFFORT` reports a dated `PATTERN_STAFFING_GAP` where a count cannot be met. The engine still checks formal job and skill eligibility, complete availability, supplied leave, shift overlap and break duration. The current Lab has no formal shift-write endpoint. Older versions and runs remain readable for audit, without changing their saved historical meaning.
